## R2 — install footprint (Methods Table 2 candidate)

Fresh `pip install --target` into a clean directory, no shared deps, measured on GLBRC scarcity-submit.glbrc.org with python 3.11.

| Tool | Install size | Package count | Architecture class |
|---|---|---|---|
| gfc 0.1.5 | 163 MB | 32 packages | native Python |
| biopython.convert | 118 MB | 32 packages | native Python (closest CLI peer) |
| bioconvert 1.2.0 | 1186 MB | 201 packages | wrapper framework |

Key facts:
- bioconvert is **7.3x heavier on disk** and **6.3x more dependencies** than gfc — this is the wrapper-tax quantified.
- biopython.convert is **27% lighter** than gfc with the same dep count — gfc cannot beat biopython.convert on dependency-light alone.
- Installing gfc + bioconvert in the same env triggers a real pandas pin conflict (gfc requires pandas<3, bioconvert pulls pandas 3.0.2). Choosing gfc means you don't need bioconvert, avoiding this conflict.

Defensible manuscript framing: gfc avoids the wrapper tax that bioconvert pays, while remaining within range of the lightest Python-CLI peer (biopython.convert).
