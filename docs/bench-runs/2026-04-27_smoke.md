## Findings

### Wins worth keeping

1. **T1 / T2 / T8 chr22 throughput is now competitive with single-purpose
   tools.** The cyvcf2 + numpy bulk encoder is the difference between
   "embarrassing" and "publishable." T1 alone went from 52 min/rep on
   2026-04-26 to 4.3 min/rep here.
2. **gfc beats AGAT at T4 by 13×.** AGAT is a Perl pipeline that does
   deep validation; gfc's tighter loop genuinely wins on this task.
3. **T2 memory story is striking.** plink2 holds the entire VCF in
   memory (1.3 GB on chr22); gfc streams (60 MB). The cluster, laptop,
   and shared-FS use cases all favour the streaming approach. This is
   probably the strongest single graphic for the paper.

### Weaknesses to be honest about

1. **T2 speed loss to plink2 (14×) and plink1.9 (8×) is real and not
   bug-shaped.** Both plink tools are highly optimised C with custom
   genotype packing; cyvcf2 + numpy is fast Python and is not going to
   close that gap. The honest framing is memory-efficient + drop-in CLI,
   not faster.
2. **T6 small-fixture comparison is not informative.** The synthetic
   4-line tblout finishes in seconds for both tools; cross-tool ratios
   are dominated by Python startup. Real-scale tblout (Pfam-A vs S288C
   proteome) is gated on the SGD download, which is failing.
3. **T7 vs handwritten biopython is a 1.5× loss.** That is the price of
   gfc's CLI / argument-validation / file-iteration scaffolding. The
   gap is small enough to be defensible but worth disclosing.

### Stage 1 fairness gaps (in priority order for the α paper)

1. **No `convertf` for T1.** EIGENSOFT not on the cluster — T1 has gfc
   numbers only, no comparison. **Highest priority gap.** T1 task
   script already detects convertf on PATH; just need the binary.
   `eigensoft` is on bioconda (last build May 2024).
2. **No UCSC chain for T5.** UCSC tools (`gff3ToGenePred`,
   `genePredToBed`) are already in the env (saw them in
   `2026-04-26_smoke.md`'s hardware.log) but the T5 task script's
   competitor block is a TODO. Implementation only.
3. **No T3 competitors.** `EMBOSS seqret`, biopython script,
   `gff3toembl` — three different competitors planned in
   `BENCHMARK_PLAN.md`, none implemented.
4. **No T8 competitor.** `pileupCaller` operates on pileup, not VCF, so
   a fair head-to-head needs a `samtools mpileup` (or VCF→pileup)
   feeder pipeline. Not a one-line fix.
5. **`correct` column is empty across all 8 tasks.** Per-task
   correctness specs are written in `2026-04-26_smoke.md`; mechanical
   to implement (~30 min × 8 = ~4 hr).
6. **T6 real-scale tblout** still gated on the SGD download.
   `download_pfam_scan.sh` retries `https://sgd-archive.yeastgenome.org/...`
   and gets `curl (35) Recv failure: Connection reset by peer` on the
   GLBRC cluster. UniProt has the same proteome at a stable URL —
   `https://rest.uniprot.org/uniprotkb/stream?...&query=proteome:UP000002311`.
7. **AGAT version string is malformed in the TSV** — "v1.4.0|" with the
   trailing pipe. Caused by `tr -s ' ' | cut -d':' -f2- | tr -d ' '`
   in `T4_gff3_to_gtf.sh:60` swallowing only spaces, not the
   table-edge `|`. Cosmetic but ugly.
